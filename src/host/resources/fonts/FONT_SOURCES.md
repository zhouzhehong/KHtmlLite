# Bundled UI fonts

Primary UI font: **Google Sans Flex** (SIL Open Font License 1.1).

- Official Google Fonts family: https://fonts.google.com/specimen/Google+Sans+Flex
- Google Fonts repository (OFL): https://github.com/google/fonts/tree/main/ofl/googlesansflex
- Variable source downloaded for static UI instances:
  `GoogleSansFlex[ROND,opsz,slnt,wdth,wght].ttf`
- Static UI instances were generated with fontTools at `opsz=14`, `wdth=100`, `slnt=0`, `ROND=0`, weights 400 and 500, for the small toolbar/address/tab text. The OFL license and copyright notices are preserved in `OFL-GoogleSansFlex.txt`; family/style names were normalized so the 400/500 faces share one Qt family.
- Font copyright: Copyright 2015 The Google Sans Flex Authors; see OFL file.

Chinese fallback: **Noto Sans SC** (SIL Open Font License 1.1).

- Official Google Fonts family: https://fonts.google.com/specimen/Noto+Sans+SC
- Google Fonts repository (OFL): https://github.com/google/fonts/tree/main/ofl/notosanssc
- Regular 400 and Medium 500 were obtained from the Google Fonts CSS service for Noto Sans SC. The Medium name table was normalized to share the `Noto Sans SC` family; copyright/license metadata is preserved.
- Font copyright: Copyright 2014-2021 Adobe, with Reserved Font Name 'Source'; see OFL file.

Apple SF Pro is **not bundled or used**: no lawful application license was established for this project and no SF Pro files were copied. The mandatory Google Sans Flex fallback is used instead.
